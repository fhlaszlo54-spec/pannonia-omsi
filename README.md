# pannonia-omsi
Íme aÜdvözöl a Pannónia Omsi Közösség hivatalos oldala! Fedezd fel saját, egyedi készítésű buszainkat, részletes festéseinket és kihívásokkal teli pályáinkat az OMSI 2 szimulátorhoz. Emellett nálunk lehetőség van az OpenOMSI projekttel közös, online multiplayer (multi) játékaimra és közösségi élményekre is a többi taggal!
